# Pop Choice
This is an chat app for recommending films by incorporating text chunking and AI embedding.

# Getting Started

Install the dependencies and run the project
```
npm install
npm start
```

## Main Requirements

<ul>
    <li>Built from scratch ✅</li>
    <li>Followed figma design ✅
    <li>Use a vector DB to embedding (used Supabase vector DB) ✅</li>
    <li>Use OpenAI API ✅</li>
    <li>Use the movies array in content.js ✅</li>
    <li>Used the React framework✅</li>
</ul>
